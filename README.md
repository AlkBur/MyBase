# 1C-like DSL Interpreter on Bun

Прототип интерпретатора DSL с синтаксисом, похожим на язык 1С:Предприятие, работающий на платформе Bun с интеграцией SQLite.

## Установка и запуск

```bash
# Установка зависимостей
bun install

# Запуск (режим разработки с автоперезагрузкой)
bun run dev

# Запуск (однократно)
bun run start

# Сборка в исполняемый файл
bun run build

# Очистка собранного бинарника и БД
bun run clean
```

## Структура проекта

```
├── index.ts              # Точка входа (инициализация БД, запуск DSL)
├── dsl-interpreter.ts    # Ядро интерпретатора
├── test-script.os        # Пример DSL скрипта
├── package.json          # Скрипты и зависимости
├── tsconfig.json         # Конфигурация TypeScript
└── data.db               # SQLite БД (создаётся автоматически)
```

## Поддерживаемый синтаксис

- Процедуры (`Процедура ... КонецПроцедуры`)
- Функции (`Функция ... КонецФункции`)
- Условные операторы (`Если ... Тогда ... Иначе ... КонецЕсли`, `ИначеЕсли`)
- Присваивание переменных
- Операции сравнения (`=`, `<>`, `>`, `<`, `>=`, `<=`)
- Логические операторы (`И`, `ИЛИ`, `НЕ`)
- Вывод сообщений (`Сообщить`)
- Возврат значения (`Возврат`)
- Создание объектов (`Новый Запрос`)
- SQLite запросы с параметрами (`&ИмяПараметра`)
